Lofi-Kawaii · KMC Apps

Privacy Policy

Effective: August 31, 2026

Summary: Lofi-Kawaii does not use OAuth or request Discord profile information. It stores a random, Activity-specific identifier on your device and records one minimal startup event to estimate unique users and return usage over a rolling one-year period. It does not transmit playback activity, track choices, volume, or environmental-effect settings.

1. Scope

This Privacy Policy explains how the KMC Apps developer team (“KMC Apps,” “we,” or “us”) handles information in connection with the Lofi-Kawaii Discord Activity (“Lofi-Kawaii” or the “Service”). Discord separately processes information under its own policies.

2. Information Lofi-Kawaii Does Not Request

The current version of Lofi-Kawaii does not:

  • use an OAuth2 login or request an OAuth access token;
  • request Discord profile data, usernames, avatars, friend lists, messages, or voice content;
  • store Discord user, server, or channel IDs in a KMC Apps database;
  • use cookies, sessionStorage, or IndexedDB;
  • use advertising, tracking pixels, cross-service tracking, or behavioral telemetry;
  • operate a KMC Apps account system or profile database; or
  • save user input, playback history, track selection, or volume preferences.

3. Information Processed on Your Device

Playback state

Track selection, play/pause state, and volume are handled in memory on your device. They are not transmitted to a KMC Apps server and reset when the Activity is reloaded or closed.

Discord SDK connection

Lofi-Kawaii uses the Discord Embedded App SDK only to establish that the Activity is ready inside Discord. The current code does not call SDK commands that request user profiles, authenticate a user, read messages, or fetch guild or channel records.

Anonymous usage measurement

To understand approximate usage, Lofi-Kawaii creates a random UUID using the browser's cryptographic API and stores it in localStorage under a key used only by this Activity. On startup, the Activity sends that identifier once to a KMC Apps Cloudflare Worker. It does not send your Discord ID, profile, playback state, selected track, volume, button activity, environmental-effect settings, country, or precise location.

The Worker converts the identifier to a keyed HMAC hash before storing it in Cloudflare D1. The database stores only that hash, the first and most recent JST usage dates, and whether the same identifier was seen on a later JST date. These records are used only to estimate unique users and the percentage that return on a different day. They represent a browser or Discord WebView storage installation, not a verified individual person.

4. Hosting and Network Information

Discord and the hosting or content-delivery provider used to serve Lofi-Kawaii may automatically process technical request information such as IP address, browser or device information (including User-Agent), access time, requested URL or asset, referring information, HTTP status, and security or error data. This information is used to deliver the Activity, maintain reliability, prevent abuse, and diagnose failures.

KMC Apps does not copy this technical request information into its anonymous usage database. Infrastructure providers determine their own technical logging and retention practices under their agreements and privacy policies.

5. Third-Party Services

  • Discord: hosts the Activity container, supplies launch context, and provides the Embedded App SDK. See the Discord Privacy Policy.
  • Hosting and delivery providers: serve the HTML, CSS, JavaScript, images, and audio required for the Activity and may process the technical request information described above.
  • Cloudflare: provides the Worker, abuse controls, and D1 database used for the anonymous usage measurement described above. See the Cloudflare Privacy Policy.

Lofi-Kawaii does not include advertising networks, social-tracking scripts, or third-party behavioral analytics.

6. Retention and Deletion

Anonymous usage records are retained until the stored identifier has not been seen for more than one year, based on JST dates, and are then deleted by a scheduled cleanup. The reported unique-user total is therefore an approximate rolling one-year total, not a permanent lifetime count. In-memory playback state ends when the page or Activity process is closed. The local anonymous identifier remains until site data is cleared or storage is otherwise reset.

Lofi-Kawaii does not add an opt-out control to the player interface. If you do not want future launches included in this anonymous measurement, do not launch the Activity or use browser or platform controls to block site storage for it, where such controls are available. Clearing the Activity's site data removes the locally stored identifier, but launching again with storage available creates a new identifier and resumes measurement; clearing data is therefore a reset, not a persistent opt-out setting.

The stored HMAC hash is not linked to a Discord account, so KMC Apps cannot locate a particular database row from a Discord username or profile. Privacy questions may be submitted through the official KMC Apps Community support server linked from Lofi-Kawaii's Discord application profile or App Directory listing. Requests concerning data controlled by Discord or another infrastructure provider should be directed to that provider.

7. Security

KMC Apps uses reasonable measures appropriate to this small Activity. The anonymous identifier is generated with a cryptographic browser API, transformed with a server-side secret before database storage, retained only for the stated period, and kept separate from Discord account information. KMC Apps also avoids unnecessary Discord API access. No internet transmission or software can be guaranteed completely secure.

8. Children

Lofi-Kawaii is not directed to anyone below the minimum age required to use Discord in their country. KMC Apps does not knowingly request personal information from children through the Activity. Users must satisfy Discord's applicable age requirements.
