Lofi-Kawaii · KMC Apps

Privacy Policy

Effective: August 28, 2026

Summary: Lofi-Kawaii does not use OAuth, request Discord profile information, operate an account or user database, use analytics, or persist your playback settings. Discord and the infrastructure used to deliver the Activity may process technical information needed to launch and serve it.

1. Scope

This Privacy Policy explains how the KMC Apps developer team (“KMC Apps,” “we,” or “us”) handles information in connection with the Lofi-Kawaii Discord Activity (“Lofi-Kawaii” or the “Service”). Discord separately processes information under its own policies.

2. Information Lofi-Kawaii Does Not Request or Store

The current version of Lofi-Kawaii does not:

  • use an OAuth2 login or request an OAuth access token;
  • request Discord profile data, usernames, avatars, friend lists, messages, or voice content;
  • store Discord user, server, or channel IDs in a KMC Apps database;
  • use cookies, localStorage, sessionStorage, or IndexedDB;
  • use analytics, advertising, tracking pixels, or behavioral telemetry;
  • operate a KMC Apps account system, application backend, or user database; or
  • save user input, playback history, track selection, or volume preferences.

3. Information Processed on Your Device

Playback state

Track selection, play/pause state, and volume are handled in memory on your device. They are not transmitted to a KMC Apps server and reset when the Activity is reloaded or closed.

Discord SDK connection

Lofi-Kawaii uses the Discord Embedded App SDK only to establish that the Activity is ready inside Discord. The current code does not call SDK commands that request user profiles, authenticate a user, read messages, or fetch guild or channel records.

4. Hosting and Network Information

Discord and the hosting or content-delivery provider used to serve Lofi-Kawaii may automatically process technical request information such as IP address, browser or device information (including User-Agent), access time, requested URL or asset, referring information, HTTP status, and security or error data. This information is used to deliver the Activity, maintain reliability, prevent abuse, and diagnose failures.

KMC Apps does not operate a separate application-access logging system or user database. Infrastructure providers determine their own technical logging and retention practices under their agreements and privacy policies.

5. Third-Party Services

  • Discord: hosts the Activity container, supplies launch context, and provides the Embedded App SDK. See the Discord Privacy Policy.
  • Hosting and delivery providers: serve the HTML, CSS, JavaScript, images, and audio required for the Activity and may process the technical request information described above.

Lofi-Kawaii does not include third-party analytics, advertising networks, or social-tracking scripts.

6. Retention and Deletion

Because Lofi-Kawaii has no KMC Apps user database, it does not retain application account data, Discord profile data, playback history, or saved preferences for deletion. In-memory playback state ends when the page or Activity process is closed. Discord and the hosting provider may retain technical request information under their own policies and configurations.

If you believe Lofi-Kawaii has retained information about you, contact KMC Apps through the official KMC Apps Community support server linked from Lofi-Kawaii's Discord application profile or App Directory listing. Please direct requests concerning data controlled by Discord or an infrastructure provider to that provider.

7. Security

KMC Apps uses reasonable measures appropriate to this small, static Activity and limits application data handling by avoiding accounts, databases, analytics, and unnecessary Discord API access. No internet transmission or software can be guaranteed completely secure.

8. Children

Lofi-Kawaii is not directed to anyone below the minimum age required to use Discord in their country. KMC Apps does not knowingly request personal information from children through the Activity. Users must satisfy Discord's applicable age requirements.

9. Changes to This Policy

KMC Apps may update this Policy when the Service, its data practices, hosting arrangements, or platform requirements change. The effective date above will be revised when an updated version is published. Material new collection or use of information will be described before or when the relevant feature is made available.

10. Contact

Privacy questions, requests, and concerns may be submitted through the official KMC Apps Community support server linked from Lofi-Kawaii's Discord application profile or App Directory listing.
