# Project audio

The production playlist contains 105 MP3 files. `src/tracks.ts` is the
canonical ordered catalog used by the player and TRACK LIST.

Vite serves these files from the app's configured base URL under `audio/`.
Author, source, and license information have not been verified in this
repository. See `CREDITS.md` for the current provenance status. Update the
playlist and provenance record together whenever the production audio set
changes.
